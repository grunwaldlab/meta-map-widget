# Changelog
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-11-02
### Added
- Added option to upload custom TSVs within the widget at runtime.
- Added option to export static images of the map as PNG or SVG.
- Added option to disable manual zoom.

### Changed
- Toolbar UI restructuring.
- Size legend scales to zoom.
- Replaced base OpenStreetMap tiles with OpenTopoMap tiles for direct `file://` use.

### Fixed
- Made TSV parsing more thorough.

## [0.1.1] - 2025-12-05
### Changed
- Renamed package to 'meta-map-widget'.

## [0.1.0] - 2025-11-14
First package version.
